# Affichage


Tout l'affichage du projet est géré par une class `Draw` qui utilise les fonctions natives de `pygame`.

Les méthodes de `Draw` sont simples : 


| Nom                       | Description                           |
| ------------------------- | ------------------------------------- |
| fill_screen               | Rempli l'écran d'une certaine couleur |
| printt_background         | Affiche le fond                       |
| refresh                   | Actualise l'acran entier              |
| draw_mino / draw_all_mino | Affiche tous les Minos                |
| draw_food / draw_all_food | Affiche toutes les nourritures        |
| draw_abundance_zone       | Affiche la zone d'abondance           |
